# 丸の内デベロッパー

丸の内のビル群を開発していく放置クリッカーゲーム。

着工エリアをタップして開発ポイント(PT)を稼ぎ、PTでビルを建てる。建てたビルは保有数に応じて
毎秒PTを自動生成し、その収益でさらに上位のビルを建てていく。保有数が増えるとスカイラインが伸びる。

## 遊び方

1. 中央の着工エリアをタップして PT を貯める
2. 下のリストからビルを購入する（購入コストは1棟買うごとに指数的に上がる）
3. ビルが自動で稼いだ PT で、より生産効率の高いビルを解放していく
4. 全8種を10棟ずつ揃えると「丸の内エリア開発率 100%」

進行状況はブラウザに自動保存され、閉じている間も最大8時間ぶんの収益が貯まる。
最初からやり直す場合は右上の設定から。

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー (Turbopack) |
| `npm run build` | 本番ビルド |
| `npm run lint` | ESLint |
| `npm run typecheck` | tsc --noEmit |

## 技術構成

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- 状態管理は React 標準（`useReducer`）、永続化は `localStorage`
- サーバーサイドの処理・外部サービスへの通信は一切なし

実装の詳細と設計方針は [CLAUDE.md](CLAUDE.md) を参照。
