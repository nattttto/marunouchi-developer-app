# 丸の内デベロッパー

三菱地所グループの事業を広げていく放置クリッカーゲーム。

着工エリアをタップして開発ポイント(PT)を稼ぎ、PTで事業を取得する。取得した事業は保有数に応じて
毎秒PTを自動生成し、その収益でさらに大きな事業へ手を伸ばしていく。
保有した施設は背景のスカイラインとして積み上がっていく。

## 遊び方

1. 中央の着工エリアをタップして PT を貯める
2. 下のリストから事業を取得する（取得費は1件買うごとに指数的に上がる）
3. 事業が自動で稼いだ PT で、より生産効率の高い事業を解放していく
4. 全21事業を10件ずつ揃えると「グループ展開率 100%」

### 事業カテゴリと倍率

事業は6つのカテゴリに分かれていて、2種類の倍率がかかる。

| カテゴリ | 例 |
|---|---|
| オフィス | 内幸町ビル、丸ビル、大手町タワー(EX) |
| 商業・ホテル | ロイヤルパークホテル、御殿場プレミアム・アウトレット、MARK IS みなとみらい |
| 住宅 | ザ・パークハビオ、ザ・パークハウス |
| インフラ・物流 | ロジクロス、高松空港 |
| 設計・サービス | CM事業、三菱地所設計、プロパティマネジメント |
| 海外 | 1251 Avenue of the Americas、8 Bishopsgate、アジア開発事業 |

- **カテゴリ倍率**：同じカテゴリを増やすと、そのカテゴリの生産量が上がる（5件で ×1.25、最大 ×3）
- **グループシナジー**：扱うカテゴリの種類が増えると、全体の生産量が上がる（2種で ×1.1、6種で ×1.75）

一点集中でも伸びるが、多角化したほうが最終的に強くなる。

なおカテゴリ名はゲームとしての分かりやすさを優先した括りで、三菱地所の公式セグメント区分とは一致しない。

進行状況はブラウザに自動保存され、閉じている間も最大8時間ぶんの収益が貯まる。
最初からやり直す場合は右上の設定から。

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー (Turbopack) |
| `npm run build` | 本番ビルド |
| `npm run lint` | ESLint |
| `npm run typecheck` | tsc --noEmit |

## 技術構成

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- 状態管理は React 標準（`useReducer`）、永続化は `localStorage`
- サーバーサイドの処理・外部サービスへの通信は一切なし

実装の詳細と設計方針は [CLAUDE.md](CLAUDE.md) を参照。
